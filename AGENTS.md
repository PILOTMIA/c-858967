- AI chat features run in Supabase Edge Functions via Lovable AI Gateway (Responses API, streamed UI-message protocol) with AI Elements on the client — keeps keys server-side and one consistent chat stack.
- COT recommendation surfaces share pairBias and tradeTiming rules; directional scores are not entry signals, and daily evidence cannot validate intraday execution.
- Market rhythm consumers use the shared useMarketRhythm query so timing evidence and historical charts read the same feed.
- Editorial chart setups are isolated from automated recommendations and reuse shared COT reads; uploaded chart levels cannot automatically establish an active entry.
- Current COT pages exclude undated editorial scenarios and unsupported fixed macro claims so report-derived guidance remains distinct from independently sourced price and news evidence.
- Editorial scenario visuals are standalone diagrams, not synthetic price histories, so unverified theses cannot be mistaken for observed market data.
- Compounding projections use a pure, tested session-based calculator separate from market feeds; risk sizing never implies or derives an expected return.
- The compounding planner has a dedicated public route and navigation entry so native production analytics can distinguish its page traffic without custom visitor storage.
- Planner lot sizing uses a tested risk/stop-cost formula, rounds down to broker volume steps, and labels dated official conversion references; projected future lots reuse current settings and are not execution recommendations.
- Uploaded COT report fixtures are reconciled against stored positions and prior-week deltas in integration tests; age-based badges describe freshness, not independent source verification.
- The top ticker and rate board share timestamped quote evidence; provider observation time determines freshness, daily references are never labeled live, and synthetic price/history fallbacks are forbidden.
- Mounted API queries are invalidated at the Arizona-time refresh checkpoints; this browser refresh is separate from backend COT synchronization.
- Current news requires a valid provider timestamp within 72 hours; unavailable feeds must not invent headlines or write empty sentiment snapshots.
- Gold and Treasury summaries use observed quotes or dated FRED series; never estimate one maturity from another, and yield differences convert percentage points to basis points.
- Macro failures return null observations, never fixed substitutes; scorecards exclude unavailable evidence and incomparable GDP units, use shared observed rhythm history, and never derive retail sentiment from COT percentages.
- Pair tools preserve selected base/quote orientation, compose returns with ratios, and calculate contract shares from counts; shared report histories are matched by full date and missing inputs never become zero-valued evidence.
- Trading Journal AI review uses each user's own Anthropic key, held only in tab memory and sent per request in the `x-claude-key` header to `analyse-chart`; there is no site-wide AI key, so the site owner pays nothing for AI analysis.
- Journal trades are written only through `save-trade` (and an owner-folder/verified DB trigger); images live in the private `chart-images` bucket under `<user id>/`, and the daily `journal-cleanup` schedule removes data of deleted accounts.
